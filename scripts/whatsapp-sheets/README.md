# חילוץ היסטוריית ווטסאפ לגוגל שיטס (Green API)

סקריפט Google Apps Script שמתחבר ל־WhatsApp דרך **Green API** ומחלץ את 100 ההודעות האחרונות
מאיש קשר או מקבוצה ישירות לגיליון.

גיליון היעד: **"חילוץ הסטוריית ווצאפ"**
`https://docs.google.com/spreadsheets/d/19pV44x9BU-fUVUJr13_poMCestdicupFx5jfLaON3Lg/edit`

## איך זה עובד

| עמודה | תוכן | מי ממלא |
|---|---|---|
| A | שם הקבוצה / איש הקשר | אתם |
| B | טלפון (לאיש קשר בלבד) | אתם |
| C | id של קבוצה | הסקריפט (או ידנית) |
| D | הסטוריה — קישור ללשונית ההודעות | הסקריפט |
| E | סטטוס | הסקריפט |
| F | עודכן | הסקריפט |

הלוגיקה בכל שורה:

1. אם עמודה **C** מלאה → מושכים לפי ה־id הזה (`<id>@g.us`).
2. אחרת, אם עמודה **B** מלאה → **איש קשר**: המספר מנורמל (`054-484-4035` → `972544844035`)
   וה־chatId הוא `972544844035@c.us`.
3. אחרת → **קבוצה**: מחפשים בלשונית "קבוצות" קבוצה שהשם שלה תואם לעמודה A,
   כותבים את ה־id שלה לעמודה C, ומושכים לפי `<id>@g.us`.

ההודעות נכתבות ללשונית נפרדת לכל שיחה בשם `שיחה · <שם>`, עם העמודות:
מספר סידורי, תאריך ושעה, כיוון (נכנסת/יוצאת), שם השולח, מספר השולח, סוג ההודעה,
טקסט, קובץ/מדיה, ומזהה ההודעה. בעמודה D בגיליון הראשי נוצר קישור ללשונית הזו.

## התקנה

1. פותחים את הגיליון → **תוספים (Extensions) ← Apps Script**.
2. מוחקים את התוכן של `Code.gs` ומדביקים את כל התוכן של
   [`Code.gs`](./Code.gs) מהתיקייה הזו.
3. אופציונלי: בגלגל השיניים ← **Show "appsscript.json" manifest file**, ומדביקים את
   [`appsscript.json`](./appsscript.json).
4. שומרים (💾), וחוזרים לגיליון ומרעננים את הדף (F5).
5. בתפריט העליון מופיע תפריט חדש: **ווטסאפ**.

## הגדרה ראשונה

1. **ווטסאפ ← 1. הגדרת Green API** — מדביקים `idInstance` ו־`apiTokenInstance`
   מהאזור האישי של Green API (console.green-api.com), ובוחרים כמות הודעות (ברירת מחדל 100).
   בפעם הראשונה גוגל תבקש אישור הרשאות — מאשרים.
2. **ווטסאפ ← 2. בדיקת חיבור** — אמור להחזיר `authorized`.
   אם לא, סורקים מחדש את ה־QR באזור האישי של Green API.
3. **ווטסאפ ← 3. רענון רשימת הקבוצות** — מושך את כל הקבוצות שהמספר שלכם חבר בהן
   ושומר אותן בלשונית "קבוצות" (שם + id). זה מה שמאפשר לחפש קבוצה לפי שם.

המפתחות נשמרים ב־`DocumentProperties` של הגיליון — לא בתאים, ולא בקוד.

## שימוש

- **ווטסאפ ← משיכת היסטוריה — השורה הנוכחית** — מריץ רק על השורה שהסמן עליה.
- **ווטסאפ ← משיכת היסטוריה — כל השורות** — מריץ על כל השורות מ־2 ומטה.

בין שורה לשורה יש השהיה של 1.2 שניות כדי לא לחרוג ממכסת הקריאות של Green API.
כל הרצה נרשמת בלשונית "לוג" (זמן, רמה, יעד, chatId, פירוט).

## נקודות חשובות

- **`getChatHistory` מחזיר רק הודעות שנשמרו במאגר של Green API** מרגע שהמופע חובר.
  היסטוריה ישנה מלפני החיבור לרוב לא תחזור — זו מגבלה של Green API, לא של הסקריפט.
- **כתובת ה־API** נגזרת אוטומטית מה־idInstance (`https://<4 ספרות ראשונות>.api.greenapi.com`).
  אם באזור האישי מופיעה כתובת אחרת, אפשר לדרוס אותה ב־Apps Script:
  **Project Settings ← Script properties**, מפתח `GREENAPI_API_URL`.
- **קידומת מדינה** ברירת מחדל `972`. לשינוי: script property `GREENAPI_COUNTRY_CODE`.
- אם שם הקבוצה מתאים לכמה קבוצות, הסקריפט עוצר ומבקש לדייק את השם או להזין id ידנית
  בעמודה C (אפשר להעתיק אותו מלשונית "קבוצות").
- מכסת Green API בתוכנית החינמית מוגבלת; משיכה של הרבה שורות ברצף עלולה להחזיר 429.

## הרצה אוטומטית (אופציונלי)

ב־Apps Script ← **Triggers ← Add Trigger**:
פונקציה `extractAllRows`, מקור `Time-driven`, למשל כל יום בשעה קבועה.
שימו לב ש־`extractAllRows` מציג חלונית סיכום בסוף — בהרצת טריגר היא פשוט לא מוצגת.

# לשונית "אנשי קשר"

נבנית ומתעדכנת אוטומטית אחרי כל חילוץ היסטוריה. כל מי ששלח הודעה נכנסת
נרשם שם — גם מקבוצות וגם משיחות פרטיות.

| עמודה | תוכן |
|---|---|
| A | מזהה — הטלפון המנורמל. זה מפתח הכפילויות |
| B | שם |
| C | שמות נוספים — אותו אדם עם שם אחר בקבוצה אחרת |
| D | טלפון |
| E | סוג — איש קשר / משתתף בקבוצה / שניהם |
| F | מקורות — `Daily - Galiluz (42) \| רוני (100)` |
| G | סה״כ הודעות |
| H–I | הודעה ראשונה ואחרונה |
| J | סיכום AI |
| K | עודכן סיכום |
| L | **הערות ידניות — הקוד לא נוגע בעמודה הזו אף פעם** |

## כללי המיזוג

- **בלי כפילויות.** המפתח הוא הטלפון המנורמל, כך שאותו אדם בשלוש קבוצות
  הוא שורה אחת.
- **בלי דריסה.** שורות לא נמחקות ולא מנוקות. `שם` נכתב רק אם התא ריק;
  שם אחר שמתגלה נצבר ל`שמות נוספים`.
- **חילוץ חוזר לא מכפיל.** `מקורות` שומר ספירה נפרדת לכל שיחה, וחילוץ
  מחדש של אותה שיחה מעדכן את הערך שלה במקום להוסיף עוד אחד.
- **טווח התאריכים מתרחב בלבד**, אף פעם לא מצטמצם.
- **הסיכום וההערות שורדים** כל חילוץ עתידי.

## סיכום AI

דורש מפתח OpenAI: **ווטסאפ ← הגדרת מפתח OpenAI**. מודל ברירת מחדל
`gpt-4o-mini`, בהתאם למה שכבר בשימוש בפרויקט.

**ווטסאפ ← סיכום AI לאנשי קשר** מסכם רק את מי שאין לו סיכום, או שהגיעו
ממנו הודעות חדשות מאז הסיכום האחרון. **סיכום AI — רענון מלא** מייצר מחדש
להכל (מחליף סיכומים קיימים; הערות ידניות לא נפגעות).

הסיכום נבנה משתי קבוצות ראיות שנאספות מכל לשוניות השיחה:
מה שהאדם כתב, ומה שאחרים כתבו עליו. המודל מקבל הוראה מפורשת לא להשלים
פרטים מהידע הכללי שלו ולסמן מסקנות משוערות — כרטיס קצר ונכון עדיף על
כרטיס מלא ומנוחש.

מגבלות ריצה: עד 25 אנשי קשר להרצה ועד 4.5 דקות, בגלל תקרת זמן הריצה של
Apps Script. אם נשארו — פשוט מריצים שוב, זה ממשיך מהמקום שנעצר.

## שימו לב

הלשונית הזו בונה פרופילים על אנשים אמיתיים מתוך הודעות פרטיות, ושולחת את
ההודעות שלהם ל-OpenAI לצורך הסיכום. שווה להחזיק את זה בראש כשמחליטים אילו
שיחות לחלץ ועם מי לשתף את הגיליון.

# תחזוקה דרך clasp (במקום הדבקה ידנית)

`clasp` הוא ה-CLI הרשמי של גוגל ל-Apps Script. אחרי הקמה חד-פעמית אפשר לערוך את
`Code.gs` כאן בריפו ולדחוף לגיליון בפקודה אחת — בלי העתק-הדבק.

## הקמה חד-פעמית

### 1. להדליק את ה-API

להיכנס ל־https://script.google.com/home/usersettings (עם החשבון שבעלים של הגיליון)
ולהדליק **Google Apps Script API**. בלי זה clasp מקבל 403.

### 2. להתקין clasp

```bash
npm install -g @google/clasp
clasp --version          # צריך 3.x
```

דורש Node 18 ומעלה.

### 3. להתחבר

```bash
clasp login              # נפתח דפדפן, בוחרים את החשבון ומאשרים
clasp show-authorized-user
```

ההרשאה נשמרת ב־`~/.clasprc.json` ושורדת בין סשנים. הקובץ הזה הוא סוד —
הוא כבר ב־`.gitignore`, לא להעתיק אותו לריפו ולא לשלוח אותו לאף אחד.

### 4. לקשר את הפרויקט

מריצים **מתוך `scripts/whatsapp-sheets/`**:

```bash
cd scripts/whatsapp-sheets
```

**אם עדיין לא הדבקתם את הקוד ב-Apps Script** — יוצרים פרויקט מקושר לגיליון:

```bash
clasp create --title "חילוץ הסטוריית ווצאפ" \
  --parentId 19pV44x9BU-fUVUJr13_poMCestdicupFx5jfLaON3Lg
```

**אם כבר הדבקתם** — לוקחים את ה-Script ID מ-Apps Script ←
`Project Settings` ← `Script ID`, ומריצים:

```bash
clasp clone <SCRIPT_ID>
git checkout Code.gs appsscript.json   # מחזירים את הגרסה שבריפו
```

שתי הדרכים יוצרות `.clasp.json` עם ה-Script ID. הקובץ הזה אינו סוד וכדאי לקמט אותו.

### 5. לדחוף

```bash
clasp show-file-status   # מראה מה יידחף
clasp push
clasp open-script        # פותח את ה-IDE לבדיקה
```

## שגרת עבודה

```bash
clasp pull    # לפני עריכה, אם נגעתם בקוד דרך הדפדפן
# ... עורכים את Code.gs ...
clasp push    # דוחפים לגיליון
```

**`clasp push` דורס את הגרסה המרוחקת.** אם ערכתם ב-IDE של Apps Script ולא עשיתם
`pull` — העריכה הזו תימחק. יש היסטוריית גרסאות ב-Apps Script אם צריך לשחזר.

`.claspignore` בתיקייה מגביל את הדחיפה ל־`Code.gs` ו־`appsscript.json` בלבד,
כך ש-`README.md` לא נדחף לפרויקט.
