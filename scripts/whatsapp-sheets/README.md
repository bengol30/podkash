# חילוץ היסטוריית ווטסאפ לגוגל שיטס (Green API)

סקריפט Google Apps Script שמתחבר ל־WhatsApp דרך **Green API** ומחלץ את 100 ההודעות האחרונות
מאיש קשר או מקבוצה ישירות לגיליון.

גיליון היעד: **"חילוץ הסטוריית ווצאפ"**
`https://docs.google.com/spreadsheets/d/19pV44x9BU-fUVUJr13_poMCestdicupFx5jfLaON3Lg/edit`

## איך זה עובד

| עמודה | תוכן | מי ממלא |
|---|---|---|
| A | שם הקבוצה / איש הקשר | אתם |
| B | טלפון (לאיש קשר בלבד) | אתם |
| C | id של קבוצה | הסקריפט (או ידנית) |
| D | הסטוריה — קישור ללשונית ההודעות | הסקריפט |
| E | סטטוס | הסקריפט |
| F | עודכן | הסקריפט |

הלוגיקה בכל שורה:

1. אם עמודה **C** מלאה → מושכים לפי ה־id הזה (`<id>@g.us`).
2. אחרת, אם עמודה **B** מלאה → **איש קשר**: המספר מנורמל (`054-484-4035` → `972544844035`)
   וה־chatId הוא `972544844035@c.us`.
3. אחרת → **קבוצה**: מחפשים בלשונית "קבוצות" קבוצה שהשם שלה תואם לעמודה A,
   כותבים את ה־id שלה לעמודה C, ומושכים לפי `<id>@g.us`.

ההודעות נכתבות ללשונית נפרדת לכל שיחה בשם `שיחה · <שם>`, עם העמודות:
מספר סידורי, תאריך ושעה, כיוון (נכנסת/יוצאת), שם השולח, מספר השולח, סוג ההודעה,
טקסט, קובץ/מדיה, ומזהה ההודעה. בעמודה D בגיליון הראשי נוצר קישור ללשונית הזו.

## התקנה

1. פותחים את הגיליון → **תוספים (Extensions) ← Apps Script**.
2. מוחקים את התוכן של `Code.gs` ומדביקים את כל התוכן של
   [`Code.gs`](./Code.gs) מהתיקייה הזו.
3. אופציונלי: בגלגל השיניים ← **Show "appsscript.json" manifest file**, ומדביקים את
   [`appsscript.json`](./appsscript.json).
4. שומרים (💾), וחוזרים לגיליון ומרעננים את הדף (F5).
5. בתפריט העליון מופיע תפריט חדש: **ווטסאפ**.

## הגדרה ראשונה

1. **ווטסאפ ← 1. הגדרת Green API** — מדביקים `idInstance` ו־`apiTokenInstance`
   מהאזור האישי של Green API (console.green-api.com), ובוחרים כמות הודעות (ברירת מחדל 100).
   בפעם הראשונה גוגל תבקש אישור הרשאות — מאשרים.
2. **ווטסאפ ← 2. בדיקת חיבור** — אמור להחזיר `authorized`.
   אם לא, סורקים מחדש את ה־QR באזור האישי של Green API.
3. **ווטסאפ ← 3. רענון רשימת הקבוצות** — מושך את כל הקבוצות שהמספר שלכם חבר בהן
   ושומר אותן בלשונית "קבוצות" (שם + id). זה מה שמאפשר לחפש קבוצה לפי שם.

המפתחות נשמרים ב־`DocumentProperties` של הגיליון — לא בתאים, ולא בקוד.

## שימוש

- **ווטסאפ ← משיכת היסטוריה — השורה הנוכחית** — מריץ רק על השורה שהסמן עליה.
- **ווטסאפ ← משיכת היסטוריה — כל השורות** — מריץ על כל השורות מ־2 ומטה.

בין שורה לשורה יש השהיה של 1.2 שניות כדי לא לחרוג ממכסת הקריאות של Green API.
כל הרצה נרשמת בלשונית "לוג" (זמן, רמה, יעד, chatId, פירוט).

## נקודות חשובות

- **`getChatHistory` מחזיר רק הודעות שנשמרו במאגר של Green API** מרגע שהמופע חובר.
  היסטוריה ישנה מלפני החיבור לרוב לא תחזור — זו מגבלה של Green API, לא של הסקריפט.
- **כתובת ה־API** נגזרת אוטומטית מה־idInstance (`https://<4 ספרות ראשונות>.api.greenapi.com`).
  אם באזור האישי מופיעה כתובת אחרת, אפשר לדרוס אותה ב־Apps Script:
  **Project Settings ← Script properties**, מפתח `GREENAPI_API_URL`.
- **קידומת מדינה** ברירת מחדל `972`. לשינוי: script property `GREENAPI_COUNTRY_CODE`.
- אם שם הקבוצה מתאים לכמה קבוצות, הסקריפט עוצר ומבקש לדייק את השם או להזין id ידנית
  בעמודה C (אפשר להעתיק אותו מלשונית "קבוצות").
- מכסת Green API בתוכנית החינמית מוגבלת; משיכה של הרבה שורות ברצף עלולה להחזיר 429.

## הרצה אוטומטית (אופציונלי)

ב־Apps Script ← **Triggers ← Add Trigger**:
פונקציה `extractAllRows`, מקור `Time-driven`, למשל כל יום בשעה קבועה.
שימו לב ש־`extractAllRows` מציג חלונית סיכום בסוף — בהרצת טריגר היא פשוט לא מוצגת.

# חלופה: Make.com (בלי קוד)

בקובץ [`make-blueprint.json`](./make-blueprint.json) יש סצנריו מוכן ל־Make שעושה
בדיוק את אותו הדבר, ומשתמש בחיבורים שכבר קיימים בחשבון:

- Google: `My Google connection (bengo0469@gmail.com)` — id 5468965
- Green API: `בנגו (7103111919 - 972527332835@c.us)` — id 6105010

## ייבוא

1. ב־Make: **Create a new scenario** ← תפריט `⋯` למטה ← **Import Blueprint**.
2. להעלות את `make-blueprint.json`.
3. לוודא שבכל מודול נבחר החיבור הנכון (אמור להיטען לבד לפי ה-id).
4. **Run once** כדי להריץ.

## מבנה הסצנריו

```
Google Sheets · Search Rows (גיליון1, שורות שיש בהן שם)
└─ Router
   ├─ מסלול 1 — יש טלפון (עמודה B)
   │    Green API · Get Chat History  (chatId = <מספר מנורמל>@c.us, count 100)
   │    Text Aggregator               (תאריך | שולח | טקסט)
   │    Google Sheets · Update Row    (כותב לעמודה D)
   └─ מסלול 2 — אין טלפון → קבוצה
        Green API · Get Contacts
        [פילטר: type = group וגם השם מכיל את עמודה A]
        Google Sheets · Update Row    (כותב את ה-id לעמודה C)
        Green API · Get Chat History  (chatId = <id>@g.us, count 100)
        Text Aggregator
        Google Sheets · Update Row    (כותב לעמודה D)
```

נרמול הטלפון נעשה בנוסחה בתוך המודול: מסירים כל תו שאינו ספרה, ואז
`00…` → חיתוך הקידומת, `972…` → כמו שהוא, `0…` → `972` + השאר, אחרת `972` + המספר.

## הערות

- `Get Chat History` מחזיר מהחדש לישן, ולכן הטקסט בעמודה D מסודר מהחדש לישן.
- הטקסט נחתך ל-49,000 תווים (מגבלת תא בגוגל שיטס היא 50,000).
- התזמון נשמר כ־`indefinitely / 900` כי on-demand לא זמין בתוכנית; משאירים
  את הסצנריו כבוי ומריצים ידנית ב־Run once.
